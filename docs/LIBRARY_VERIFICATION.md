# プロジェクト専用ライブラリの照合記録

確認日 2026年11月17日。27シンボルと、実際に使用する29種のフットプリントをプロジェクト内に保存した。`sym-lib-table` と `fp-lib-table` は `${KIPRJMOD}/lib/…` を参照する。回路図のシンボルキャッシュも埋込み済み。グローバルのMy-Libraryやダウンロードフォルダへの参照は使用していない。インストール先に依存する3Dモデル参照はコピーから外した。

`PIN_PAD_AUDIT.csv` は全124部品のシンボル端子集合と、割り当てた実ファイルのパッド番号集合を照合した結果。全件一致。以下のメーカーとの照合は、番号の一致だけでは判別できない端子機能、極性、パッケージ寸法を補足する。

## CYA0650の作成ランドと制約

SHOUHAN承認仕様書の本体A=6.6±0.2、B=7.2±0.2、C=5.0max、電極D=1.5±0.5、E=3.0±0.2mmに基づく。本資料に推奨ランドがないため、非極性の端子1/2として、中心x=±2.1mm、銅箔3.8×3.4mm、独立したペースト開口3.0×1.8mmを作成した。本体と電極の公差を考慮した拡大パターンであり、メーカー指定の推奨ランドの転記ではない。PCBA工程でのランド/ペーストレビューと初品実装確認が残る。

## 出典とライセンス

元データと変更の機械可読記録は `library_sources.json`、メーカー資料のURLと取得成否は `datasheets/sources.json`、参照した資料は `DESIGN_REPORT.md` の末尾を参照。

標準図形と標準パターンの出典はローカルKiCad 9ライブラリ（[KiCad Symbols](https://gitlab.com/kicad/libraries/kicad-symbols)、[KiCad Footprints](https://gitlab.com/kicad/libraries/kicad-footprints)）。KiCadライブラリのCC BY-SA 4.0とKiCad Library Exceptionの条件を引き継ぐ。派生元の図形・パターンを独自のメーカー提供データとは表示していない。

新規または修正したものは、LM5060/LMR51610/LM66100/TMUX2821/RA4M1/TM1640等の機能別シンボル、OSL専用番号、主FETの番号とソースランド分割、OSLのTHTパターン、CYA0650のランド、PANJIT SS2040FLの推奨ランド。OSLはDP_A/DP_K/CC_AGの極性表示が重ならないよう図形幅を15.24mmに拡大した。型番を持つシンボルには、正しいValueとプロジェクト内の既定フットプリントも設定した。SnapEDAの未照合CADモデルは取り込んでいない。LTV-817のメーカーPDFはSnapEDAの公開ミラーから取得した。
